# Пошук будинку в Тернополі

Щоденний звіт про приватні будинки та земельні ділянки в Тернополі й вибраному передмісті.

- [Актуальний звіт на GitHub Pages](https://andriy232.github.io/ternopil_house/)
- Локальний звіт: `latest_report/index.html` — головна сторінка «Актуальні сторінки». Навігація веде на окремі сторінки карти, відсіяних і видалених оголошень, кадастру та проаналізованих сайтів.
- Архіви запусків: `%TEMP%\house_search\<час_пошуку>`

Windows Task Scheduler запускає `run-daily.ps1` щодня о 09:00 за київським часом. Після успішного повного запуску сценарій публікує `latest_report`, створює Git-коміт за наявності змін і виконує push у `main`. GitHub Actions розгортає вміст `latest_report` на GitHub Pages.

`render_report.py` розподіляє рядки `listings.json` за `section=active|excluded|removed` і створює всі HTML-сторінки. Рядок з явно знятими оголошеннями автоматично потрапляє до `removed`; недоступність через 403/429 сама собою не вважається видаленням. `run-daily.ps1` запускає генератор і публікує кожну сторінку разом із локальними фото.
